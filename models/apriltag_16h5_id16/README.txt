AprilTag tag16h5, ID 16
======================

The codeword is 0x063A (ID 16 is the 17th entry in the official zero-indexed
tag16h5 code array). The family has 30 valid IDs, numbered 0 through 29.

Files:
- urdf/tag16h5_id16.urdf
- meshes/tag16h5_id16.dae
- materials/textures/tag16h5_id16.png

The tag face is 0.10 m x 0.10 m, lies in the XY plane, and faces +Z.
Collision geometry is a 1 mm thick square.

Keep the folder structure intact so the DAE can locate its texture.
The URDF uses a relative mesh path; if your URDF loader resolves relative
paths differently, replace it with an absolute path or a package:// URI.
